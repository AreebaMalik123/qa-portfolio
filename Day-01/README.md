# Day 01 – SQA Traineeship

## Overview
This folder contains my Day 1 learning tasks and practical activities as part of the SQA Traineeship at Alif Algorithm.

## Project
**Application Under Test:** [SauceDemo](https://www.saucedemo.com/)

## Tasks & Activities

### Part A – Testing Fundamentals
Studied the basic concepts of Software Quality Assurance and Software Testing, including:
- Quality Assurance (QA)
- Quality Control (QC)
- Software Testing
- Error, Defect, and Failure
- Seven Principles of Software Testing

### Part B – SauceDemo Feature Inventory
Explored SauceDemo as a customer and identified application features across different sections.

The feature inventory covered:
- Login
- Products Page
- Product Sorting
- Product Details
- Add to Cart
- Remove from Cart
- Shopping Cart
- Checkout Process
- Side Menu and Logout

### Part C – Screenshots
Captured application screenshots to document the testing exploration:
- Login Page
- Products Page
- Shopping Cart Page

## Key Learnings
- Understanding the fundamentals of Software Testing.
- Learning the difference between QA and QC.
- Understanding errors, defects, and failures.
- Exploring application features from a tester's perspective.
- Learning how to prepare a feature inventory.
- Understanding the importance of identifying application functionality before testing.
