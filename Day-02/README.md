# Day 02 – SQA Traineeship

## Overview
This folder contains my Day 2 tasks and learning activities as part of the SQA Traineeship at Alif Algorithm.

## Project
**Application Under Test:** [SauceDemo](https://www.saucedemo.com/)

## Tasks Completed

### Part A – User Stories
Created 8 user stories for the following SauceDemo features:
- Login
- Product Sorting
- Product Details
- Add to Cart
- Remove from Cart
- Cart Page
- Checkout Information
- Order Completion

### Part B – Acceptance Criteria
- Wrote acceptance criteria for all 8 user stories.
- Used Given / When / Then format.
- Included positive and negative test scenarios.
- Prepared at least 3 acceptance criteria for each user story.

### Part C – Software Testing Life Cycle (STLC)
Documented all six STLC phases:
1. Requirement Analysis
2. Test Planning
3. Test Case Design
4. Test Environment Setup
5. Test Execution
6. Test Closure

Included activities, entry criteria, and exit criteria for each phase.

### Part D – Bonus
Waterfall and Scrum methodology comparison.

## Key Learnings
- Understanding User Stories and Acceptance Criteria.
- Learning the Given / When / Then format.
- Understanding SDLC and STLC.
- Learning the basics of Agile and Scrum.
- Understanding entry and exit criteria in software testing.
