## Topics Covered

### 1. Software Testing Levels

Learned about the four main testing levels:

- **Unit Testing:** Testing individual components of an application.
- **Integration Testing:** Testing how different components work together.
- **System Testing:** Testing the complete application.
- **Acceptance Testing (UAT):** Checking whether the application meets user requirements.

### 2. Functional vs Non-Functional Testing

- **Functional Testing:** Verifies what the application does.
- **Non-Functional Testing:** Verifies how well the application works, including speed, usability, security, and compatibility.

### 3. Smoke, Sanity, Regression & Retesting

- **Smoke Testing:** Checking the basic features of a new build to ensure they are working.
- **Sanity Testing:** Checking whether a specific fix or change works correctly.
- **Regression Testing:** Checking whether a new change has affected existing functionality.
- **Retesting:** Testing a previously failed test case again after the bug has been fixed.

### 4. Basic Bug Reporting

Learned the essential elements of a bug report:

- Bug Title
- Build and Device
- Steps to Reproduce
- Expected Result
- Actual Result
- Screenshot or Screen Recording

## Practice Task – SauceDemo

Practised the four testing types using the SauceDemo website.

1. **Smoke Testing:** Checked login, product listing, and shopping cart functionality to verify that the main features were working.
2. **Sanity Testing:** Checked the product sorting feature after a specific change to verify that products were displayed in the correct order.
3. **Regression Testing:** Tested login, product listing, shopping cart, and checkout after a change to ensure existing features were still working.
4. **Retesting:** Tested the Add to Cart button again after a reported issue was fixed to confirm that the product could be added successfully.
